\hypertarget{dir_bb5131a20addbc994671e47370d8e244_autotoc_md7466}{}\doxysubsubsubsection{\texorpdfstring{Root}{Root}}\label{dir_bb5131a20addbc994671e47370d8e244_autotoc_md7466}
Contains all parts of a dialog. Use {\ttfamily should\+Scale\+Background} to enable background scaling, it requires an element with {\ttfamily \mbox{[}data-\/vaul-\/drawer-\/wrapper\mbox{]}} data attribute to scale its background. Can be controlled with the {\ttfamily value} and {\ttfamily on\+Open\+Change} props. Can be opened by default via the {\ttfamily open} prop.

Additional props\+:

{\ttfamily close\+Threshold}\+: Number between 0 and 1 that determines when the drawer should be closed. Example\+: threshold of 0.\+5 would close the drawer if the user swiped for 50\% of the height of the drawer or more.

{\ttfamily scroll\+Lock\+Timeout}\+: Duration for which the drawer is not draggable after scrolling content inside of the drawer. Defaults to 500ms.

{\ttfamily snap\+Points}\+: Array of numbers from 0 to 100 that corresponds to \% of the screen a given snap point should take up. Should go from least visible. Example {\ttfamily \mbox{[}0.\+2, 0.\+5, 0.\+8\mbox{]}}. You can also use px values, which doesn\textquotesingle{}t take screen height into account.

{\ttfamily fade\+From\+Index}\+: Index of a {\ttfamily snap\+Point} from which the overlay fade should be applied. Defaults to the last snap point.

{\ttfamily modal}\+: When {\ttfamily false} it allows to interact with elements outside of the drawer without closing it. Defaults to {\ttfamily true}.

{\ttfamily direction}\+: Direction of the drawer. Can be {\ttfamily top} or {\ttfamily bottom}, {\ttfamily left}, {\ttfamily right}. Defaults to {\ttfamily bottom}.

{\ttfamily reposition\+Inputs}\+: When {\ttfamily true} Vaul will reposition inputs rather than scroll then into view if the keyboard is in the way. Setting it to {\ttfamily false} will fall back to the default browser behavior.

{\ttfamily no\+Body\+Styles}\+: When {\ttfamily true} the {\ttfamily body} doesn\textquotesingle{}t get any styles assigned from Vaul.

{\ttfamily handle\+Only}\+: When {\ttfamily true} only allows the drawer to be dragged by the {\ttfamily \texorpdfstring{$<$}{<}Drawer.\+Handle /\texorpdfstring{$>$}{>}} component. Defaults to {\ttfamily false}.

{\ttfamily set\+Background\+Color\+On\+Scale}\+: When {\ttfamily false} we don\textquotesingle{}t change body\textquotesingle{}s background color when the drawer is open. {\ttfamily true} by default.

{\ttfamily default\+Open}\+: Opened by default, still reacts to {\ttfamily open} state changes.

{\ttfamily dismissible}\+: When {\ttfamily false} dragging, clicking outside, pressing esc, etc. will not close the drawer. Use this in comination with the {\ttfamily open} prop, otherwise you won\textquotesingle{}t be able to open/close the drawer.

{\ttfamily snap\+To\+Sequential\+Point}\+: Disabled velocity based swiping for snap points. This means that a snap point won\textquotesingle{}t be skipped even if the velocity is high enough. Useful if each snap point in a drawer is equally important.

{\ttfamily on\+Animation\+End}\+: Gets triggered after the open or close animation ends, it receives an {\ttfamily open} argument with the {\ttfamily open} state of the drawer by the time the function was triggered. Useful to revert any state changes for example.

{\ttfamily \mbox{[}data-\/vaul-\/no-\/drag\mbox{]}}\+: When interacting with an element with this data attribute, the drawer won\textquotesingle{}t be dragged.\hypertarget{dir_bb5131a20addbc994671e47370d8e244_autotoc_md7467}{}\doxysubsubsubsection{\texorpdfstring{Controlled Drawer}{Controlled Drawer}}\label{dir_bb5131a20addbc994671e47370d8e244_autotoc_md7467}
Drawer can be controlled programmatically by providing the {\ttfamily open} prop. If you want to react to open state changes from within the Drawer use the {\ttfamily on\+Open\+Change} prop, this will allow you to provide your own open state while still closing the drawer when the escape key is pressed for example.
