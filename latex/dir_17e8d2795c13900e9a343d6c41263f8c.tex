Type\+: {\ttfamily string}

String with ANSI escape codes. Like one styled by \href{https://github.com/chalk/chalk}{\texttt{{\ttfamily chalk}}}. Newline characters will be normalized to {\ttfamily \textbackslash{}n}.\hypertarget{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7866}{}\doxysubsubsubsection{\texorpdfstring{columns}{columns}}\label{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7866}
Type\+: {\ttfamily number}

Number of columns to wrap the text to.\hypertarget{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7867}{}\doxysubsubsubsection{\texorpdfstring{options}{options}}\label{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7867}

Type\+: {\ttfamily boolean}\textbackslash{} Default\+: {\ttfamily false}

By default the wrap is soft, meaning long words may extend past the column width. Setting this to {\ttfamily true} will make it hard wrap at the column width.\hypertarget{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7869}{}\doxysubsubsubsubsection{\texorpdfstring{word\+Wrap}{word\+Wrap}}\label{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7869}
Type\+: {\ttfamily boolean}\textbackslash{} Default\+: {\ttfamily true}

By default, an attempt is made to split words at spaces, ensuring that they don\textquotesingle{}t extend past the configured columns. If word\+Wrap is {\ttfamily false}, each column will instead be completely filled splitting words as necessary.\hypertarget{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7870}{}\doxysubsubsubsubsection{\texorpdfstring{trim}{trim}}\label{dir_17e8d2795c13900e9a343d6c41263f8c_autotoc_md7870}
Type\+: {\ttfamily boolean}\textbackslash{} Default\+: {\ttfamily true}

Whitespace on all lines is removed by default.
