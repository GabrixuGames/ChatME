\hypertarget{dir_7c7bc6465e52377577b5be9b25d03e75_autotoc_md3719}{}\doxysubsection{\texorpdfstring{How it works}{How it works}}\label{dir_7c7bc6465e52377577b5be9b25d03e75_autotoc_md3719}
There\textquotesingle{}s currently no native OTP/2\+FA/\+MFA input in HTML, which means people are either going with 1. a simple input design or 2. custom designs like this one. This library works by rendering an invisible input as a sibling of the slots, contained by a {\ttfamily relative}ly positioned parent (the container root called {\itshape OTPInput}).\hypertarget{dir_7c7bc6465e52377577b5be9b25d03e75_autotoc_md3720}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{dir_7c7bc6465e52377577b5be9b25d03e75_autotoc_md3720}
This is the most complete OTP input on the web. It\textquotesingle{}s fully featured

{\bfseries{Supports screen readers (a11y)}}\begin{adjustwidth}{1em}{0em}


Stripe was my first inspiration to build this library.

Take a look at Stripe\textquotesingle{}s input. The screen reader does not behave like it normally should on a normal single input. That\textquotesingle{}s because Stripe\textquotesingle{}s solution is to render a 1-\/digit input with "{}clone-\/divs"{} rendering a single char per div.

\href{https://github.com/guilhermerodz/input-otp/assets/10366880/3d127aef-147c-4f28-9f6c-57a357a802d0}{\texttt{https\+://github.\+com/guilhermerodz/input-\/otp/assets/10366880/3d127aef-\/147c-\/4f28-\/9f6c-\/57a357a802d0}}

So we\textquotesingle{}re rendering a single input with invisible/transparent colors instead. The screen reader now gets to read it, but there is no appearance. Feel free to build whatever UI you want\+:

\href{https://github.com/guilhermerodz/input-otp/assets/10366880/718710f0-2198-418c-8fa0-46c05ae5475d}{\texttt{https\+://github.\+com/guilhermerodz/input-\/otp/assets/10366880/718710f0-\/2198-\/418c-\/8fa0-\/46c05ae5475d}}

\end{adjustwidth}

{\bfseries{Automatically optimizes for password managers}}\begin{adjustwidth}{1em}{0em}


For password managers such as Last\+Pass, 1Password, Dashlane or Bitwarden, {\ttfamily input-\/otp} will automatically detect them in the page and increase input width by \texorpdfstring{$\sim$}{\string~}40px to trick the password manager\textquotesingle{}s browser extension and prevent the badge from rendering to the last/right slot of the input.




\begin{DoxyItemize}
\item {\bfseries{This feature is optional and it\textquotesingle{}s enabled by default. You can disable this optimization by adding {\ttfamily push\+Password\+Manager\+Strategy="{}none"{}}.}}
\item {\bfseries{This feature does not cause visible layout shift.}}
\end{DoxyItemize}

\end{adjustwidth}

{\bfseries{\mbox{[}Workaround\mbox{]} If you want to block specific password manager/badges\+:}}\begin{adjustwidth}{1em}{0em}


By default, {\ttfamily input-\/otp} handles password managers for you. The password manager badges should be automatically shifted to the right side.

However, if you still want to block password managers, please disable the {\ttfamily push\+Password\+Manager\+Strategy} and then manually block each PWM.
