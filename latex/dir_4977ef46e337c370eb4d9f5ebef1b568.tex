\begin{quote}
Get the visual width of a string -\/ the number of columns required to display it \end{quote}


Some Unicode characters are \href{https://en.wikipedia.org/wiki/Halfwidth_and_fullwidth_forms}{\texttt{fullwidth}} and use double the normal width. \href{https://en.wikipedia.org/wiki/ANSI_escape_code}{\texttt{ANSI escape codes}} are stripped and doesn\textquotesingle{}t affect the width.

Useful to be able to measure the actual width of command-\/line output.\hypertarget{dir_4977ef46e337c370eb4d9f5ebef1b568_autotoc_md6500}{}\doxysubsection{\texorpdfstring{Install}{Install}}\label{dir_4977ef46e337c370eb4d9f5ebef1b568_autotoc_md6500}
