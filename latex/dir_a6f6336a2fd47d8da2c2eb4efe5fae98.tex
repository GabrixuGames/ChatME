\doxysubsection{Detailed Description}
\hypertarget{dir_a6f6336a2fd47d8da2c2eb4efe5fae98_autotoc_md742}{}\doxysubsection{\texorpdfstring{Intro}{Intro}}\label{dir_a6f6336a2fd47d8da2c2eb4efe5fae98_autotoc_md742}
The prerequisite for this code mod is to migrate your usages to the new syntax, so overloads for hooks and {\ttfamily Query\+Client} methods shouldn\textquotesingle{}t be available anymore.\hypertarget{dir_a6f6336a2fd47d8da2c2eb4efe5fae98_autotoc_md743}{}\doxysubsubsection{\texorpdfstring{Affected usages}{Affected usages}}\label{dir_a6f6336a2fd47d8da2c2eb4efe5fae98_autotoc_md743}
Please note, this code mod transforms usages only where the first argument is an object expression.

The following usage should be transformed by the code mod\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{const\ \{\ data\ \}\ =\ useQuery(\{}
\DoxyCodeLine{\ \ queryKey:\ ['posts'],}
\DoxyCodeLine{\ \ queryFn:\ queryFn,}
\DoxyCodeLine{\ \ keepPreviousData:\ true,}
\DoxyCodeLine{\})}

\end{DoxyCode}


But the following usage won\textquotesingle{}t be transformed by the code mod, because the first argument an identifier\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{const\ hookArgument\ =\ \{}
\DoxyCodeLine{\ \ queryKey:\ ['posts'],}
\DoxyCodeLine{\ \ queryFn:\ queryFn,}
\DoxyCodeLine{\ \ keepPreviousData:\ true,}
\DoxyCodeLine{\}}
\DoxyCodeLine{const\ \{\ data\ \}\ =\ useQuery(hookArgument)}

\end{DoxyCode}
