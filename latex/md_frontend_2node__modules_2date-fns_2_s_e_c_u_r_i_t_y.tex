Security updates are applied only to the latest release.\hypertarget{md_frontend_2node__modules_2date-fns_2_s_e_c_u_r_i_t_y_autotoc_md2447}{}\doxysection{\texorpdfstring{Reporting a Vulnerability}{Reporting a Vulnerability}}\label{md_frontend_2node__modules_2date-fns_2_s_e_c_u_r_i_t_y_autotoc_md2447}
If you have discovered a security vulnerability in this project, please report it privately. {\bfseries{Do not disclose it as a public issue.}} This gives us time to work with you to fix the issue before public exposure, reducing the chance that the exploit will be used before a patch is released. Please disclose it to \href{mailto:koss@nocorp.me}{\texttt{Sasha Koss}}. This project is maintained by a team of volunteers on a reasonable-\/effort basis. As such, please give us at least 90 days to work on a fix before public exposure.
