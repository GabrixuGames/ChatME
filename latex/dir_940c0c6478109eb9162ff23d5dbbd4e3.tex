\doxysubsection{Detailed Description}
\href{https://tailwindcss.com/docs/typography-plugin}{\texttt{  }} 

The official Tailwind CSS Typography plugin provides a set of {\ttfamily prose} classes you can use to add beautiful typographic defaults to any vanilla HTML you don’t control, like HTML rendered from Markdown, or pulled from a CMS.


\begin{DoxyCode}{0}
\DoxyCodeLine{<article\ class="{}prose\ lg:prose-\/xl"{}>\{\{\ markdown\ \}\}</article>}

\end{DoxyCode}


To see what it looks like in action, check out our \href{https://play.tailwindcss.com/uj1vGACRJA?layout=preview}{\texttt{live demo}} on Tailwind Play.
