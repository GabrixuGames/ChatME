SWC (stands for {\ttfamily Speedy Web Compiler}) is a super-\/fast Type\+Script / Java\+Script compiler written in Rust. It\textquotesingle{}s a library for Rust and Java\+Script at the same time. If you are using SWC from Rust, see \href{https://rustdoc.swc.rs/swc/}{\texttt{rustdoc}} and for most users, your entry point for using the library will be \href{https://rustdoc.swc.rs/swc_ecma_parser/}{\texttt{parser}}.

Also, SWC tries to ensure that

\begin{quote}
If you select the latest version of each crates, it will work \end{quote}


for rust users.

MSRV of crates is currently {\ttfamily 1.\+73}.

To update all SWC crates you use, you can run {\ttfamily curl \href{https://raw.githubusercontent.com/swc-project/swc/main/scripts/update-all-swc-crates.sh}{\texttt{https\+://raw.\+githubusercontent.\+com/swc-\/project/swc/main/scripts/update-\/all-\/swc-\/crates.\+sh}} \texorpdfstring{$\vert$}{|} bash -\/s}. This script will update all dependencies to the latest version and run {\ttfamily cargo build} to ensure that everything works. Note that you need


\begin{DoxyItemize}
\item {\ttfamily jq}
\item {\ttfamily cargo upgrade}
\end{DoxyItemize}

command to run the script.

Supported Node Versions\+:


\begin{DoxyItemize}
\item Node v10+ for usage
\item Node v20+ for development
\end{DoxyItemize}
